# Simulador de Interfaz IoT

Simulador web interactivo de panel de control IoT (Interacción Hombre-Máquina) para control y visualización de estados en pines GPIO (GPIO 4 y GPIO 5).

## 🚀 Características
- Control interactivo de estados ON / OFF para pines GPIO 4 y GPIO 5.
- Interfaz moderna, responsiva y adaptable.
- Simulación directa en el navegador web sin necesidad de hardware físico (ESP8266/ESP32).
